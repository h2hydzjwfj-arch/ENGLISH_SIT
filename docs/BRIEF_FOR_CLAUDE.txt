Привет, Claude. Я Роман. Мне нужен полный редизайн (только визуальная часть)
премиального сайта для изучения английского языка — iomaenglish.

Функциональность уже работает. Стиль — уродский. Нужно сделать дорого,
элегантно, профессионально. Аудитория: состоятельные взрослые люди,
которые ценят своё время. Уровень восприятия — как у частного репетитора
за 100 000 руб/час или как у Apple/Loro Piana. Никакого Duolingo.

═══════════════════════════════════════════════════════════════════════════════
КОНЦЕПЦИЯ ПРОДУКТА
═══════════════════════════════════════════════════════════════════════════════

Пользователь заходит → проходит диагностику → AI определяет уровень по CEFR
(A1–C2) → строит персональную программу на основе Murphy (Essential / English
/ Advanced Grammar in Use) + Cambridge и Oxford → ведёт к свободному
владению английским.

Ключевые модули (уже работают):
1. Главная — представление продукта
2. Диагностический тест — 5 секций (Grammar, Reading, Listening, Writing, Speaking)
3. Дашборд — прогресс, уровень, стрик, программа из юнитов Murphy
4. Урок — теория + упражнения с проверкой
5. Vocabulary — SRS (интервальное повторение по SM-2)
6. Speaking Lab — запись голоса + AI-фидбэк
7. Listening Lab — аудио + транскрипт + проверка
8. Writing Lab — эссе + оценка по 4 критериям Cambridge

═══════════════════════════════════════════════════════════════════════════════
ЧТО ИМЕННО НУЖНО ОТ ТЕБЯ
═══════════════════════════════════════════════════════════════════════════════

Переделать ТОЛЬКО CSS и particles.js (космос). HTML-структуру и JS-логику
НЕ менять, если не согласовано. Все классы сохранить.

Что подлежит полной переработке:
• styles.css      — главный файл, от него наследуют все страницы
• test.css        — стили теста
• dashboard.css   — стили дашборда
• lesson.css      — стили урока
• vocabulary.css  — стили словаря
• speaking.css    — стили speaking lab
• listening.css   — стили listening lab
• writing.css     — стили writing lab
• particles.js    — космос (звёзды + метеоры) в тёмной теме

Что нельзя трогать:
• server.js, lib/*.js — логика и API
• *.html              — структура и тексты
• *.js (кроме particles.js) — логика
• package.json, .env

НАПРАВЛЕНИЕ ПО ДИЗАЙНУ
═══════════════════════════════════════════════════════════════════════════════

1. ТИПОГРАФИКА
   Сейчас: Playfair Display (заголовки) + Inter (текст). Скучно и по-детски.
   Нужно: премиальная пара. Варианты для размышления: Fraunces, GT Sectra,
   Editorial New, Canela, Romie для заголовков; Inter Display, Söhne,
   Untitled Sans, Manrope для текста.
   Дай точную пару + веса + примеры применения.

2. ЦВЕТ
   Сейчас: тёмный фон + золото, выглядит дёшево.
   Идея: глубокий графит / изумруд / бордо / слоновая кость — сдержанная
   классическая палитра.
   Тёмная тема: НЕ чистый чёрный, а #0b0d10 или #0e1014.
   Светлая тема: тёплый off-white #f8f7f4, НЕ белый.
   Дай точные HEX + CSS-переменные.

3. КОМПОНЕНТЫ
   Пересмотри: кнопки, карточки, поля ввода, плашки уровней, прогресс-бары,
   чипы, модалки. Всё должно быть единой дизайн-системой. Радиусы, тени,
   границы, hover/active — единые правила.

4. АНИМАЦИИ
   Минимум, но элегантно. 200–400мс, cubic-bezier. Никаких bounce/spring.
   Плавные переходы. Появление блоков при скролле. Тонкое поднятие на hover.

5. КОСМОС (тёмная тема)
   Направление нравится, но нужен редизайн:
   • Метеоры РЕДКИЕ (раз в 15–30 секунд), а не каждые 5
   • Звёзды очень мелкие (0.3–0.6px), почти пыль, с медленным мерцанием
   • Никаких больших созвездий
   • Палитра: белый + холодный голубой + 5% тёплых золотых

6. СВЕТЛАЯ ТЕМА
   Убрать всё детское. Тёплый фон (крем, бумага), тонкие тени, тонкие
   границы, один акцентный цвет.

const LEVELS = [
  { code:'A1', name:'Beginner',           ru:'Начальный',      color:'#a8b3c4' },
  { code:'A2', name:'Elementary',         ru:'Элементарный',   color:'#7d9fc7' },
  { code:'B1', name:'Intermediate',       ru:'Средний',        color:'#4a8fc7' },
  { code:'B2', name:'Upper-Intermediate', ru:'Выше среднего',  color:'#2f6fa8' },
  { code:'C1', name:'Advanced',           ru:'Продвинутый',    color:'#c9a961' },
  { code:'C2', name:'Proficiency',        ru:'Свободный',      color:'#e8c878' }
];
function idx(c){ return LEVELS.findIndex(l => l.code === c); }
function next(c){ const i = idx(c); return (i >= 0 && i < LEVELS.length - 1) ? LEVELS[i+1] : null; }
function fromScore(p){
  if (p < 25) return 'A1'; if (p < 45) return 'A2'; if (p < 65) return 'B1';
  if (p < 80) return 'B2'; if (p < 92) return 'C1'; return 'C2';
}
function progressToNext(code, p){
  const ranges = { A1:[0,25], A2:[25,45], B1:[45,65], B2:[65,80], C1:[80,92], C2:[92,100] };
  const r = ranges[code] || [0,100];
  if (p <= r[0]) return 0;
  if (p >= r[1]) return 100;
  return Math.round(((p - r[0]) / (r[1] - r[0])) * 100);
}
module.exports = { LEVELS, idx, next, fromScore, progressToNext };

function nextReview(card, quality){
  let { interval = 0, ease = 2.5, reps = 0 } = card;
  if (quality < 3){ reps = 0; interval = 1; }
  else {
    reps++;
    if (reps === 1) interval = 1;
    else if (reps === 2) interval = 3;
    else interval = Math.round(interval * ease);
    ease = Math.max(1.3, ease + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02)));
  }
  const due = Date.now() + interval * 24 * 60 * 60 * 1000;
  return { interval, ease: Math.round(ease * 100) / 100, reps, due };
}
module.exports = { nextReview };

function readProfile(id){
  if (!id) return null;
  try { return JSON.parse(fs.readFileSync(path.join(PROGRESS_DIR, id + '.json'), 'utf8')); }
  catch(e){ return null; }
}
function writeProfile(id, data){
  fs.mkdirSync(PROGRESS_DIR, { recursive: true });
  fs.writeFileSync(path.join(PROGRESS_DIR, id + '.json'), JSON.stringify(data, null, 2), 'utf8');
}
function ensureProfile(req, res){
  let id = req.cookies && req.cookies.profile;
  let p = id ? readProfile(id) : null;
  if (!p){
    id = 'u_' + crypto.randomBytes(8).toString('hex');
    res.cookie('profile', id, { httpOnly: true, sameSite: 'lax', maxAge: 365*24*3600*1000 });
    p = { id, createdAt: Date.now(), level: null, testScores: null, testPercent: 0, progressToNext: 0, streak: 0, lastVisit: null, lastStreakDay: null, lessonsDone: 0, unitProgress: {}, vocabulary: [], achievements: [], history: [], lessonHistory: [] };
    writeProfile(id, p);
  }
  return p;
}

app.get('/api/me', (req, res) => {
  const p = ensureProfile(req, res);
  const today = new Date().toISOString().slice(0,10);
  if (p.lastStreakDay !== today){
    const y = new Date(Date.now() - 86400000).toISOString().slice(0,10);
    if (p.lastStreakDay === y) p.streak = (p.streak || 0) + 1;
    else p.streak = 1;
    p.lastStreakDay = today;
  }
  p.lastVisit = Date.now();
  writeProfile(p.id, p);
  res.json({ ok: true, profile: p });
});

app.post('/api/test/submit', (req, res) => {
  const p = ensureProfile(req, res);
  const a = (req.body && req.body.answers) || {};
  const scores = { grammar:Number(a.grammar)||0, reading:Number(a.reading)||0, listening:Number(a.listening)||0, writing:Number(a.writing)||0, speaking:Number(a.speaking)||0 };
  const total = (scores.grammar + scores.reading + scores.listening + scores.writing + scores.speaking) / 5;
  const percent = Math.round(total);
  const level = cefr.fromScore(percent);
  const progress = cefr.progressToNext(level, percent);

  res.json({ ok: true, level, percent, progress, scores });
});

app.post('/api/lesson/complete', (req, res) => {
  const p = ensureProfile(req, res);
  const { unitId, correct, total } = req.body || {};
  if (!unitId) return res.status(400).json({ ok:false });
  p.unitProgress = p.unitProgress || {};
  const prev = p.unitProgress[unitId] || { tries:0, correct:0, total:0, best:0 };
  const percent = Math.round(((Number(correct)||0) / (Number(total)||1)) * 100);
  prev.tries++; prev.correct += Number(correct)||0; prev.total += Number(total)||1;
  prev.best = Math.max(prev.best, percent); prev.lastAt = Date.now();
  p.unitProgress[unitId] = prev;
  p.lessonsDone = (p.lessonsDone || 0) + 1;
  if (percent >= 60 && p.testPercent != null){
    p.testPercent = Math.min(100, p.testPercent + 1);
    p.level = cefr.fromScore(p.testPercent);
    p.progressToNext = cefr.progressToNext(p.level, p.testPercent);
  }
  writeProfile(p.id, p);
  res.json({ ok:true, unit:prev, level:p.level });
});

async function ollamaChat(system, user, maxTokens){
  const url = (process.env.OLLAMA_URL || 'http://localhost:11434') + '/api/chat';
  const r = await fetch(url, {
    method: 'POST', headers:{'Content-Type':'application/json'},
    body: JSON.stringify({ model: process.env.OLLAMA_MODEL || 'qwen2.5:7b', messages:[{role:'system',content:system},{role:'user',content:user}], stream:false, options:{ temperature:0.5, num_predict:maxTokens||700, num_ctx:8192 } }),
    signal: AbortSignal.timeout(60000)
  });
  if (!r.ok) throw new Error('Ollama ' + r.status);
  const d = await r.json();
  return String((d && d.message && d.message.content) || '').trim();
}
async function groqChat(system, user, maxTokens){
  const key = process.env.GROQ_API_KEY;
  if (!key) throw new Error('no groq');
  const r = await fetch('https://api.groq.com/openai/v1/chat/completions', {
    method:'POST', headers:{'Authorization':'Bearer '+key,'Content-Type':'application/json'},
    body: JSON.stringify({ model:'llama-3.3-70b-versatile', messages:[{role:'system',content:system},{role:'user',content:user}], max_tokens:maxTokens||700, temperature:0.5 }),
    signal: AbortSignal.timeout(30000)
  });
  if (!r.ok) throw new Error('Groq ' + r.status);
  const d = await r.json();
  return String(d.choices && d.choices[0] && d.choices[0].message && d.choices[0].message.content || '').trim();
}
async function aiText(system, user, maxTokens){
  try { return await ollamaChat(system, user, maxTokens); } catch(e){ console.warn('[ai] ollama:', e.message); }
  try { return await groqChat(system, user, maxTokens); } catch(e){ console.warn('[ai] groq:', e.message); }
  throw new Error('AI недоступен');
}

(function(){
  if (window.__iomaParticles) return;
  window.__iomaParticles = true;
  var canvas, ctx, dpr, W, H, raf;
  var stars = [], meteors = [];
  var nextMeteorAt = Date.now() + 4000;
  function initCanvas(){
    if (canvas) return;
    canvas = document.createElement('canvas');
    canvas.id = 'iomaParticlesCanvas';
    canvas.style.cssText = 'position:fixed;top:0;left:0;width:100vw;height:100vh;pointer-events:none;z-index:0;opacity:0;transition:opacity 1s';
    document.body.appendChild(canvas);
    ctx = canvas.getContext('2d');
    resize();
    window.addEventListener('resize', resize);
  }
  function resize(){
    dpr = Math.max(1, Math.min(2, window.devicePixelRatio || 1));
    W = window.innerWidth; H = window.innerHeight;
    canvas.width = W * dpr; canvas.height = H * dpr;
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    rebuild();
  }
  function rebuild(){
    stars = [];
    var n = Math.max(300, Math.min(800, Math.round(W / 2.2)));
    for (var i = 0; i < n; i++){
      var big = Math.random() < 0.06;
      var hue = Math.random();
      var color = hue < 0.75 ? 'white' : (hue < 0.92 ? 'gold' : 'blue');
      stars.push({
        x: Math.random() * W, y: Math.random() * H,
        r: big ? (1.3 + Math.random() * 1.1) : (0.3 + Math.random() * 0.7),
        tw: Math.random() * Math.PI * 2, sp: 0.012 + Math.random() * 0.05,
        alpha: 0.35 + Math.random() * 0.65, big: big, color: color
      });
    }
  }
  function spawnMeteor(){
    var fromRight = Math.random() < 0.75;
    var startX, startY;
    if (fromRight){ startX = W * (0.15 + Math.random() * 0.85); startY = -40; }
    else { startX = W + 60; startY = H * (0.02 + Math.random() * 0.4); }
    var angle = Math.PI * 0.72 + (Math.random() - 0.5) * Math.PI * 0.42;
    var speed = 5.5 + Math.random() * 4;
    meteors.push({ x:startX, y:startY, vx:Math.cos(angle)*speed, vy:Math.abs(Math.sin(angle))*speed, life:0, maxLife:200, len:150+Math.random()*150, alpha:0.85+Math.random()*0.15, size:1.8+Math.random()*1.3 });
    nextMeteorAt = Date.now() + 8000 + Math.random() * 9000;
  }
  function draw(){
    if (!ctx) return;
    ctx.clearRect(0, 0, W, H);
    for (var i = 0; i < stars.length; i++){
      var p = stars[i];
      p.tw += p.sp;
      var t = (p.tw % (Math.PI * 2)) / (Math.PI * 2);
      var flick = t < 0.15 ? (t / 0.15) : (1 - (t - 0.15) / 0.85);
      var a = p.alpha * (0.15 + 0.85 * flick);
      var col;
      if (p.color === 'gold') col = 'rgba(232,200,120,' + a.toFixed(3) + ')';
      else if (p.color === 'blue') col = 'rgba(180,210,255,' + a.toFixed(3) + ')';
      else col = 'rgba(255,255,255,' + a.toFixed(3) + ')';
      if (p.big){
        var g = ctx.createRadialGradient(p.x, p.y, 0, p.x, p.y, p.r * 6);
        g.addColorStop(0, col); g.addColorStop(1, 'rgba(255,255,255,0)');
        ctx.fillStyle = g; ctx.beginPath(); ctx.arc(p.x, p.y, p.r * 6, 0, Math.PI * 2); ctx.fill();
      }
      ctx.fillStyle = col; ctx.beginPath(); ctx.arc(p.x, p.y, p.r, 0, Math.PI * 2); ctx.fill();
    }
    if (meteors.length === 0 && Date.now() > nextMeteorAt) spawnMeteor();
    for (var k = meteors.length - 1; k >= 0; k--){
      var m = meteors[k]; m.x += m.vx; m.y += m.vy; m.life++;
      var la = m.alpha * (1 - m.life / m.maxLife);
      var tailX = m.x - m.vx * (m.len / 10), tailY = m.y - m.vy * (m.len / 10);
      var grad = ctx.createLinearGradient(m.x, m.y, tailX, tailY);
      grad.addColorStop(0, 'rgba(255,255,255,' + la + ')');
      grad.addColorStop(0.25, 'rgba(232,200,120,' + (la * 0.75) + ')');
      grad.addColorStop(1, 'rgba(201,169,97,0)');

  function toggleRecord(){
    var btn = $('#recordBtn'), label = $('#recordLabel');
    var SR = window.SpeechRecognition || window.webkitSpeechRecognition;
    if (!SR){ alert('Голосовой ввод не поддерживается в этом браузере'); return; }
    if (recording){
      recording = false;
      if (recognition) recognition.stop();
      if (recordTimer) clearInterval(recordTimer);
      btn.classList.remove('recording');
      label.textContent = 'Говорить снова';
      return;
    }
    recognition = new SR();
    recognition.lang = 'en-US';
    recognition.continuous = true;
    recognition.interimResults = true;
    var final = state.speakingTranscript || '';
    recognition.onresult = function(e){
      var interim = '';
      for (var i = e.resultIndex; i < e.results.length; i++){
        var t = e.results[i][0].transcript;
        if (e.results[i].isFinal) final += t + ' ';
        else interim += t;
      }
      state.speakingTranscript = (final + interim).trim();
      $('#transcriptBox').hidden = false;
      $('#transcriptText').textContent = state.speakingTranscript;
      updateNav();
    };
    recognition.onerror = function(){ recording = false; btn.classList.remove('recording'); label.textContent = 'Говорить снова'; if (recordTimer) clearInterval(recordTimer); };
    recognition.onend = function(){ recording = false; btn.classList.remove('recording'); if (recordTimer) clearInterval(recordTimer); label.textContent = state.speakingTranscript.length >= 20 ? 'Записать снова' : 'Говорить'; };
    recognition.start();
    recording = true;
    btn.classList.add('recording');
    label.textContent = 'Стоп';
    recordStart = Date.now();
    var timerEl = $('#recordTimer');
    recordTimer = setInterval(function(){
      var s = Math.floor((Date.now() - recordStart) / 1000);
      timerEl.textContent = String(Math.floor(s / 60)).padStart(2,'0') + ':' + String(s % 60).padStart(2,'0');
      if (s >= 90) toggleRecord();
    }, 300);
  }
  function calcScores(){
    var gCorrect = state.grammarAnswers.filter(function(a, i){ return a === GRAMMAR[i].correct; }).length;
    var gPercent = Math.round((gCorrect / GRAMMAR.length) * 100);
    var rCorrect = state.readingAnswers.filter(function(a, i){ return a === READING.questions[i].correct; }).length;
    var rPercent = Math.round((rCorrect / READING.questions.length) * 100);
    var lPercent = state.listeningAnswer === LISTENING.correct ? 100 : 0;
    var wLen = state.writingText.trim().length;
    var wWords = state.writingText.trim().split(/\s+/).filter(Boolean).length;
    var wPercent = Math.min(100, Math.round((wLen / 200) * 60) + (wWords >= 30 ? 40 : 0));
    var sLen = state.speakingTranscript.trim().length;
    var sPercent = Math.min(100, Math.round((sLen / 150) * 100));
    return { gPercent:gPercent, rPercent:rPercent, lPercent:lPercent, wPercent:wPercent, sPercent:sPercent };
  }
  function scoreToLevel(p){
    if (p < 25) return 'A1';
    if (p < 45) return 'A2';
    if (p < 65) return 'B1';
    if (p < 80) return 'B2';
    if (p < 92) return 'C1';
    return 'C2';
  }
  function renderResult(){
    var s = calcScores();
    var overall = Math.round((s.gPercent + s.rPercent + s.lPercent + s.wPercent + s.sPercent) / 5);
    var level = scoreToLevel(overall);
    var names = { A1:'Beginner', A2:'Elementary', B1:'Intermediate', B2:'Upper-Intermediate', C1:'Advanced', C2:'Proficiency' };
    $('#resultLevel').textContent = level;
    $('#resultName').textContent = names[level];
    var profile = [
      { label:'Grammar', level:scoreToLevel(s.gPercent) },
      { label:'Reading', level:scoreToLevel(s.rPercent) },
      { label:'Listening', level:scoreToLevel(s.lPercent) },
      { label:'Writing', level:scoreToLevel(s.wPercent) },
      { label:'Speaking', level:scoreToLevel(s.sPercent) }
    ];
    $('#resultProfile').innerHTML = profile.map(function(p){
      return '<div class="rp-item"><div class="rp-label">' + p.label + '</div><div class="rp-level">' + p.level + '</div></div>';
    }).join('');
    var strengths = profile.filter(function(p){ return p.level > level; }).map(function(p){ return p.label; });
    var weaknesses = profile.filter(function(p){ return p.level < level; }).map(function(p){ return p.label; });
    var summary = '';
    if (strengths.length) summary += '💪 Сильные стороны: <b>' + strengths.join(', ') + '</b>. ';
    if (weaknesses.length) summary += '📈 Стоит подтянуть: <b>' + weaknesses.join(', ') + '</b>. ';
    summary += 'Программа обучения будет адаптирована под ваш профиль.';
    $('#resultSummary').innerHTML = summary;
    fetch('/api/test/submit', {
      method:'POST', headers:{'Content-Type':'application/json'}, credentials:'same-origin',
      body: JSON.stringify({ answers: { grammar:s.gPercent, reading:s.rPercent, listening:s.lPercent, writing:s.wPercent, speaking:s.sPercent } })
    }).catch(function(){});
  }
  function next(){
    var s = state.section;
    if (s === 'grammar'){
      if (state.grammarIdx < GRAMMAR.length - 1){ state.grammarIdx++; renderGrammar(); }
      else show('reading');
      return;
    }
    if (s === 'reading') return show('listening');
    if (s === 'listening') return show('writing');
    if (s === 'writing') return show('speaking');
    if (s === 'speaking'){ renderResult(); return show('result'); }
  }
  function back(){
    var s = state.section;
    if (s === 'grammar'){ if (state.grammarIdx > 0){ state.grammarIdx--; renderGrammar(); } else show('welcome'); return; }
    if (s === 'reading') return show('grammar');
    if (s === 'listening') return show('reading');
    if (s === 'writing') return show('listening');
    if (s === 'speaking') return show('writing');
  }
  function init(){
    $('#startTest').addEventListener('click', function(){ show('grammar'); });
    $('#nextBtn').addEventListener('click', next);
    $('#backBtn').addEventListener('click', back);
    $('#playBtn').addEventListener('click', playAudio);
    $('#recordBtn').addEventListener('click', toggleRecord);
    $('#restartBtn').addEventListener('click', function(){ location.reload(); });
    if ('speechSynthesis' in window){ speechSynthesis.getVoices(); speechSynthesis.onvoiceschanged = function(){ speechSynthesis.getVoices(); }; }
  }
  if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', init);
  else init();
})();

(function(){
  var btn = document.getElementById('themeToggle');
  try {
    var saved = localStorage.getItem('iomaeng_theme');
    if (saved === 'light') document.documentElement.classList.add('light');
    else if (saved === 'dark') document.documentElement.classList.remove('light');
    else if (matchMedia('(prefers-color-scheme: light)').matches) document.documentElement.classList.add('light');
  } catch(e){}
  if (btn) btn.addEventListener('click', function(){
    var isLight = document.documentElement.classList.toggle('light');
    try { localStorage.setItem('iomaeng_theme', isLight ? 'light' : 'dark'); } catch(e){}
  });
  var params = new URLSearchParams(location.search);
  var unitId = params.get('id');
  var level = params.get('level') || 'A1';
  var state = { answers:[], submitted:false, unit:null };
  function esc(s){ return String(s == null ? '' : s).replace(/[&<>"']/g, function(c){ return {'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c]; }); }
  if (!unitId){ document.getElementById('lessonTitle').textContent = 'Lesson not found'; return; }
  fetch('/api/curriculum?level=' + level, { credentials:'same-origin' })
    .then(function(r){ return r.json(); })
    .then(function(d){
      if (!d || !d.ok){ document.getElementById('lessonTitle').textContent = 'Error'; return; }
      var unit = d.units.find(function(u){ return u.id === unitId; });
      if (!unit){ document.getElementById('lessonTitle').textContent = 'Not found'; return; }
      state.unit = unit;
      state.answers = unit.exercises.map(function(){ return null; });
      render(d.book, unit);
    }).catch(function(e){ console.warn(e); });
  function render(book, unit){
    document.getElementById('lessonEyebrow').textContent = 'Lesson · ' + unit.id.toUpperCase();
    document.getElementById('lessonTitle').textContent = unit.title;
    document.getElementById('lessonBook').textContent = book;
    document.getElementById('lessonGrammar').textContent = unit.grammar;
    renderExercises();
    updateProgress();
  }
  function renderExercises(){
    var host = document.getElementById('exerciseHost');
    var letters = ['A','B','C','D'];
    host.innerHTML = state.unit.exercises.map(function(ex, i){
      var selected = state.answers[i];
      return '<div class="exercise" data-i="' + i + '"><div class="ex-q">' + (i + 1) + '. ' + esc(ex.q) + '</div><div class="ex-options">'
        + ex.options.map(function(o, j){
          var cls = 'ex-opt';
          if (state.submitted){
            if (j === ex.correct) cls += ' correct';
            else if (j === selected) cls += ' wrong';
          } else if (selected === j) cls += ' selected';
          return '<button type="button" class="' + cls + '" data-q="' + i + '" data-o="' + j + '"' + (state.submitted ? ' disabled' : '') + '><span class="ex-letter">' + letters[j] + '</span><span>' + esc(o) + '</span></button>';
        }).join('')
        + '</div><div class="ex-comment" data-i="' + i + '"></div></div>';
    }).join('');
    host.querySelectorAll('.ex-opt').forEach(function(b){
      b.addEventListener('click', function(){
        if (state.submitted) return;
        state.answers[Number(b.dataset.q)] = Number(b.dataset.o);
        renderExercises();
        updateProgress();
      });
    });
    if (state.submitted){
      state.unit.exercises.forEach(function(ex, i){
        var box = document.querySelector('.ex-comment[data-i="' + i + '"]');
        if (box){
          var isRight = state.answers[i] === ex.correct;
          box.textContent = isRight ? '✓ Correct' : ('✗ Correct answer: ' + ex.options[ex.correct]);
          box.classList.add('show');
        }
      });
    }
  }
  function updateProgress(){
    var done = state.answers.filter(function(a){ return a != null; }).length;
    var total = state.unit ? state.unit.exercises.length : 0;
    var pct = total ? Math.round((done / total) * 100) : 0;
    document.getElementById('plFill').style.width = pct + '%';
    document.getElementById('plText').textContent = done + ' / ' + total;
    document.getElementById('nextBtn').disabled = done < total;

  }

    if (!state.submitted){
      state.submitted = true;

      renderExercises();
      fetch('/api/lesson/complete', {
        method:'POST', headers:{'Content-Type':'application/json'}, credentials:'same-origin',
        body: JSON.stringify({ unitId: state.unit.id, correct: correct, total: state.unit.exercises.length })
      }).catch(function(){});
      updateProgress();
      var pct = Math.round((correct / state.unit.exercises.length) * 100);
      document.getElementById('lrScore').textContent = correct + ' из ' + state.unit.exercises.length + ' (' + pct + '%)';
      setTimeout(function(){ document.getElementById('lessonResult').hidden = false; }, 900);
    } else location.href = '/dashboard';
  });
  document.getElementById('backBtn').addEventListener('click', function(){ history.back(); });
  document.getElementById('againBtn').addEventListener('click', function(){ location.reload(); });
})();

  }

  function toggleRecord(){
    var SR = window.SpeechRecognition || window.webkitSpeechRecognition;
    if (!SR){ alert('Голосовой ввод не поддерживается'); return; }
    var btn = document.getElementById('spkBtn'), label = document.getElementById('spkLabel');
    if (recording){
      recording = false;
      if (recognition) recognition.stop();
      if (timerInterval) clearInterval(timerInterval);
      btn.classList.remove('recording');
      label.textContent = 'Говорить снова';
      return;
    }
    recognition = new SR();
    recognition.lang = 'en-US';
    recognition.continuous = true;
    recognition.interimResults = true;
    var final = transcript || '';
    recognition.onresult = function(e){
      var interim = '';
      for (var i = e.resultIndex; i < e.results.length; i++){
        var t = e.results[i][0].transcript;
        if (e.results[i].isFinal) final += t + ' ';
        else interim += t;
      }
      transcript = (final + interim).trim();
      document.getElementById('spkTranscript').hidden = false;
      document.getElementById('stText').textContent = transcript;
    };
    recognition.onend = function(){
      recording = false;
      btn.classList.remove('recording');
      if (timerInterval) clearInterval(timerInterval);
      label.textContent = transcript.length >= 20 ? 'Записать снова' : 'Говорить';
    };
    recognition.onerror = function(){ recording = false; btn.classList.remove('recording'); if (timerInterval) clearInterval(timerInterval); };
    recognition.start();
    recording = true;
    btn.classList.add('recording');
    label.textContent = 'Стоп';
    startTime = Date.now();
    var timerEl = document.getElementById('spkTimer');
    timerInterval = setInterval(function(){

    var it = ITEMS[idx];
    var utt = new SpeechSynthesisUtterance(it.text);
    utt.lang = (it.accent === 'American') ? 'en-US' : 'en-GB';
    utt.rate = rate;
    var voices = speechSynthesis.getVoices();
    var target = voices.find(function(v){ return v.lang === utt.lang; }) || voices.find(function(v){ return v.lang && v.lang.indexOf('en') === 0; });
    if (target) utt.voice = target;
    speechSynthesis.cancel();

    var matched = user.filter(function(w){ return orig.indexOf(w) !== -1; }).length;
    var accuracy = Math.round((matched / Math.max(orig.length, 1)) * 100);
    var uniq = {}; user.forEach(function(w){ uniq[w] = 1; });
    var covers = Math.round((Object.keys(uniq).length / orig.length) * 100);

(function(){
  var btn = document.getElementById('themeToggle');
  try {
    var saved = localStorage.getItem('iomaeng_theme');
    if (saved === 'light') document.documentElement.classList.add('light');
    else if (saved === 'dark') document.documentElement.classList.remove('light');
    else if (matchMedia('(prefers-color-scheme: light)').matches) document.documentElement.classList.add('light');
  } catch(e){}
  if (btn) btn.addEventListener('click', function(){
    var isLight = document.documentElement.classList.toggle('light');
    try { localStorage.setItem('iomaeng_theme', isLight ? 'light' : 'dark'); } catch(e){}
  });
  var TASKS = null, currentTask = null;
  fetch('/api/writing-tasks').then(function(r){ return r.json(); }).then(function(d){
    if (d && d.ok && d.items){ TASKS = d.items; pickTask(); }
  });
  function pickTask(){
    if (!TASKS || !TASKS.length) return;
    currentTask = TASKS[Math.floor(Math.random() * TASKS.length)];
    document.getElementById('wtText').innerHTML = currentTask.text;
    document.getElementById('wrtResult').hidden = true;
  }
  document.getElementById('newTaskBtn').addEventListener('click', pickTask);
  var ta = document.getElementById('wrtInput');
  var counter = document.getElementById('wrtCount');
  var checkBtn = document.getElementById('checkWritingBtn');
  var resultEl = document.getElementById('wrtResult');
  ta.addEventListener('input', function(){
    var len = ta.value.length;
    var words = ta.value.trim().split(/\s+/).filter(Boolean).length;
    counter.textContent = len + ' символов · ' + words + ' слов';
    checkBtn.disabled = len < 80;
  });
  checkBtn.addEventListener('click', function(){
    var text = ta.value.trim();
    if (text.length < 80){ alert('Слишком короткий текст'); return; }
    checkBtn.disabled = true;
    checkBtn.textContent = 'AI проверяет...';
    fetch('/api/writing/check', {
      method:'POST', headers:{'Content-Type':'application/json'}, credentials:'same-origin',
      body: JSON.stringify({ text: text, task: currentTask ? currentTask.text : 'free', level: currentTask ? currentTask.level : 'B1' })
    })
      .then(function(r){ return r.json(); })
      .then(function(d){
        checkBtn.disabled = false;
        checkBtn.textContent = 'Проверить с AI';
        if (!d || !d.ok){ alert((d && d.error) || 'Ошибка'); return; }
        renderResult(d.result);
      })
      .catch(function(e){ checkBtn.disabled = false; checkBtn.textContent = 'Проверить с AI'; alert(e.message); });
  });
  function renderResult(r){
    resultEl.hidden = false;
    var score = r.score || 0;
    var html = '<div class="wr-top"><div class="wr-overall"><div class="wr-lvl">' + (r.overall || '—') + '</div><div class="wr-sc">Overall level</div></div><div class="wr-score-big">' + score + '<span>/100</span></div></div>';
    if (r.criteria){
      var labels = { task:'Task Achievement', coherence:'Coherence & Cohesion', vocabulary:'Lexical Resource', grammar:'Grammatical Range' };
      html += '<div class="wr-criteria">';
      Object.keys(labels).forEach(function(k){
        var c = r.criteria[k]; if (!c) return;
        html += '<div class="wr-crit"><div class="wr-crit-head"><span>' + labels[k] + '</span><span class="wr-crit-score">' + (c.score || 0) + '</span></div><div class="wr-crit-bar"><div class="wr-crit-fill" style="width:' + (c.score || 0) + '%"></div></div><div class="wr-crit-comment">' + (c.comment || '') + '</div></div>';
      });
      html += '</div>';
    }
    if (r.strengths && r.strengths.length) html += '<div class="wr-section"><h4>Strengths</h4><ul>' + r.strengths.map(function(s){ return '<li>' + s + '</li>'; }).join('') + '</ul></div>';
    if (r.improvements && r.improvements.length) html += '<div class="wr-section"><h4>Improvements</h4><ul>' + r.improvements.map(function(s){ return '<li>' + s + '</li>'; }).join('') + '</ul></div>';
    if (r.corrected) html += '<div class="wr-section"><h4>Corrected version</h4><div class="wr-corrected">' + r.corrected + '</div></div>';
    resultEl.innerHTML = html;
    resultEl.scrollIntoView({ behavior:'smooth', block:'start' });
  }
})();
